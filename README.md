==================================================

01. THE MASTER DESIGN PRINCIPLE

==================================================

Follow this principle everywhere:

DESIGN FOR HUMANS FIRST.

BEAUTY SECOND.

COMPLEXITY NEVER.

Never add complexity simply because a modern website can technically support it.

A feature is valuable only when it makes the user's task easier.

A visual effect is valuable only when it improves hierarchy, atmosphere or understanding.

A section is valuable only when it answers a real customer question.

A button is valuable only when the user understands what happens after clicking it.

When uncertain:

REMOVE.

When two solutions are possible:

CHOOSE THE SIMPLER ONE.

When beauty and usability conflict:

USABILITY WINS.

When marketing language and truth conflict:

TRUTH WINS.
